# ニコニコ動画 コメント表示調整

[English](README.md) | **日本語** | [简体中文](README.zh-CN.md)

ニコニコ動画のコメントの**大きさ**と**不透明度**を調整するユーザースクリプトです。

## 機能

- **コメントの大きさ**：50%〜150%（2種類の方式から選択）
- **コメントの不透明度**：10%〜100%
- **表示言語**：日本語／简体中文／繁體中文／English（初期設定はブラウザの言語に従う。手動切り替えも可能）
- 設定はブラウザに保存され、ページを再読み込みしても保持されます
- 全画面表示にも対応
- PC 版（`www.nicovideo.jp`）とスマートフォン版（`sp.nicovideo.jp`）に対応

## インストール

1. [Tampermonkey](https://www.tampermonkey.net/) や [Violentmonkey](https://violentmonkey.github.io/) などのユーザースクリプトマネージャーをインストールします。
2. `niconico-comment-tweaker.js` を開き、ユーザースクリプトマネージャーでインストールします。
3. ニコニコ動画の動画ページを開きます（開いている場合は再読み込みしてください）。

## 使い方

次のどちらかで設定パネルを開きます。

- 画面**左下の青い丸ボタン**をクリック
- **Alt+C** を押す（macOS では Option+C）

### 設定項目

| 項目 | 説明 |
| --- | --- |
| サイズ調整方式 | コメントの大きさを変える方式（下記参照） |
| サイズ | コメントの大きさ。100% が元の大きさです |
| 不透明度 | コメント層の不透明度。値が大きいほどはっきり、小さいほど透けて表示されます。初期値は 80% です |
| 言語 | 設定パネルの表示言語。「自動」はブラウザの言語に従います |
| 初期設定に戻す | サイズと不透明度の設定を初期値に戻します（言語設定はそのまま） |

### サイズ調整方式

- **フォントモード**（初期設定）：コメントを描画するときの文字サイズを変更します。変更は、調整後に流れてくるコメントから反映されます。最大まで大きくすると、コメントの端が少し重なることがあります。
- **スプライトモード**：描画済みのコメント画像をそのまま拡大縮小し、変更はすぐに反映されます。大きくするとコメント同士が重なりやすくなります。
- **サイズを変更しない**：不透明度だけを調整します。
